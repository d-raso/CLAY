The cell death/pop visual that the user finally approved (2026-06-16) is a **lingering cytoplasm spill**: `CellFx.CytoplasmSpill` (Assets/_Scripts/Gameplay/CellFx.cs) spawns translucent green goo blobs that spray out, settle, and HOLD as a remnant before fading. It is called synchronously from `CellBiomass.Pop()` so it never depends on the deflate coroutine. The cell body itself deflates via `mass → MinMass` + `ApplyGrowth` (stable, volume preservation stays ON).

Hard-won lessons (avoid repeating the ~8-iteration saga):
- The user wants death to leave a **remnant/spill**, NOT shrink-and-vanish. A deflate alone reads as "disappear."
- Do NOT disable VolumePreservation or hack spring rest-lengths during death — it launches the soft body to infinity ("goes crazy").
- Project is on the **URP 2D Renderer**; BioSlime is a **Sprite Lit** Shader Graph. A 3D/PBR Lit shader renders unlit/black here. A 2D-lit material goes BLACK under a Spot light with Multiply blend — needs a **Global Light2D**.
- The "PBR cytoplasm" detour (CytoplasmLit2D shader, CytoplasmSkin runtime texture, CytoplasmTextureBaker) was rejected — opaque/polka-dot and worse than BioSlime. The cell's CytoplasmMesh MeshRenderer should use the **BioSlimeFill** material on the **Shader Graphs/BioSlime** shader.
- `Mathf.SmoothStep(a,b,t)` is NOT HLSL smoothstep (it blends by t, ignoring edges) — a frequent bug source in the procedural texture code.
- Remote-driving the editor to verify FX is unreliable: ~90s domain reloads, sub-second effects can't be screenshotted, and inspector-set mass triggers `OnValidate` which doesn't reliably start coroutines. Have the USER playtest.

2026-08-11 — POP and EATEN are now VISUALLY DISTINCT (were identical; both called one PhysicalDeathRoutine). In `CellBiomass`: `Pop()`→`PopDeathRoutine` (internal-pressure failure: a **wind-up tell** — brief swell+jitter via `InflateSoftBody(swell)` for ~0.22s with volume STILL enabled, then hide + outward violent burst: Hitstop/Shockwave/PressureWave/MetaballBurst/MembraneFragments/CytoplasmSpill). `Consumed(ICell by)`→`EatenDeathRoutine(predator)` (absorption: hide body, `CellFx.Engulf` sucks a mesh snapshot toward the predator + peels membrane inward, `CellFx.CytoplasmSiphon` streams droplets INTO the predator, and the predator `PlayEatFeedback` = gulp bulge + prey-colour flash via `CellFx.AbsorbPulse`). Shared tail `FinishDeath(prevGrowKeys)` (destroy AI / respawn player). Mnemonic: **pop throws matter OUT + leaves a mess; eaten pulls matter IN + feeds predator.** NOTE the "never hack spring rest-lengths" rule below still holds for the RUPTURE — the wind-up inflation is safe only because volume stays ON (pulls it back) and it's a modest +22% for 0.22s, then SetMass()/ApplyGrowth() restores exact rest-lengths. Also earlier 2026-08-11: violent-burst overhaul, then pieces made smaller/thinner/slower per user (MembraneFragments len 0.18–0.42×, y*0.16, vel 3.5–6.5×; metaball blob vel 3.5–7×). Verified compiles + pop runs exception-free; eaten path built but not staged live (AI rarely completes an engulf; sub-second FX unscreenshottable — user should playtest).

2026-08-11 (part 3) — POP now drops EDIBLE cytoplasm gobbets (gameplay, not just FX). `CytoGobbet.SpawnBurst(center, radius, cellMass, organelles, color)` (Assets/_Scripts/Gameplay/CytoGobbet.cs) is called from `PopDeathRoutine` (replaced the transient MetaballBurst+CytoplasmSpill; kept Hitstop/Shockwave/PressureWave/MembraneFragments). Each gobbet = a Quad + CLAY/MetaballGoo single-blob material (looks like the pop goo) + trigger CircleCollider2D + Rigidbody2D + `EdibleEntity`. Total edible mass = cellMass × cyto-fraction, SPLIT across gobbets by area (bigger gobbet = more mass). Gobbets drift on the flow field, then dissolve (fade+shrink) after a lifetime; if a cell overlaps one, the existing `Engulfment`→`EdibleEntity.Consume` path grants biomass+matter. Tuning on `CytoGobbetConfig` singleton (auto-creates a fallback if not in scene; add to GameplaySystems to expose sliders): `baseCytoFraction` 0.7, `organelleMassCut` 0.08/organelle (organelle count from new `EvolutionNodes.OrganelleCount`), `baseDissolveTime` 6s, and PLACEHOLDER water-condition sliders (temperature/salinity/acidity + influence weights) → `DissolveTime()` (harsher water dissolves faster — to be wired to real per-region chemistry later). GOTCHA fixed: `CreatePrimitive(Quad)` ships a MeshCollider; must `DestroyImmediate` it BEFORE `AddComponent<Rigidbody2D>()` (deferred Destroy still conflicts → null rb). Open design note: a freshly-popped player sitting on its own gobbets re-eats them fast (recovers mass); may want a brief self-eat delay or wider burst if that's undesired.

2026-08-16 — APPROVED pop look: `PopShell` (Assets/_Scripts/Gameplay/PopShell.cs). The swarm + separate CytoGobbets read as bubbles; user's fix (which worked): treat the pop as ONE expanding metaball SHELL "visible only in some parts", driven by invisible mass-points. PopShell = a single CLAY/MetaballGoo quad fed by N (~10–24, = r×4) mass-points that start on a small ring (0.4×r) and blow OUTWARD; because it's one fused surface, neighbours merge into ARCS and the gaps open as points spread → breaks apart, never separate bubbles. Each point carries an invisible kinematic trigger CircleCollider2D + EdibleEntity (mass ∝ its area, total = cellMass×cytoFraction) as a child; Engulfment eats them and the goo vanishes there (Push() drops eaten/dead points from the `_Blobs` array; detects eaten via child GO == null). Uneaten points thin out (radius Lerp(1→0.06, t)) and DustPoof at end-of-life (`CytoGobbetConfig.DissolveTime()`). `CellBiomass.PopDeathRoutine` now: wind-up → Hitstop/Shockwave/PressureWave/RuptureMembrane/CytoplasmCloud → hide body → `PopShell.Burst(pos, Radius, mass, organelles, FxColor())`. Removed the CytoplasmSwarm + CytoGobbet.SpawnBurst + CytoplasmBurst(mist) calls from pop (methods/classes still exist, unused). Tunables live in PopShell.Init (expand vel 4–6.5×r, drag 2.2, threshold 1.25) + CytoGobbetConfig (cyto fraction, organelle cut, dissolve time, placeholder water-condition sliders).
