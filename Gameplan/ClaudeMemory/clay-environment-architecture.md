CLAY's SampleScene has TWO environment systems coexisting:
- **Legacy** (children of `Environment`): InfiniteBackground, Caustics, Particles, LightShafts — older, mostly superseded.
- **Active/new** (scene-root objects): WorldBackground, WaterCaustics, FloatingParticles, OrganicMatter, FlowFieldManager, plus `PlanetaryEnvironment`.

`PlanetaryEnvironment` (added 2026-06-14) is the authority. Each tick it samples the player position, computes a climate temperature from `latitude` (+base), blends biomes via [[BiomeLibrary]] (`Assets/_Scripts/Environment/BiomeLibrary.cs`), and pushes global shader props: `_BiomeDeepColor/_BiomeMidColor/_BiomeShallowColor`, `_BiomeMurkiness`, `_CausticStrength/_CausticColor`, `_BiomeParticleColor/Density`, `_BiomeOrganicColor/Density`, plus `_WaterTemperature/_WaterTurbulence/_GlobalFlowDirection`. WorldBackground.shader and WaterCaustics.shader have built-in fallback palettes so they aren't black if PlanetaryEnvironment is absent.

Three-tier control (by design): broad = planetary latitude/temperature; medium = per-biome Perlin presence blobs in world space; fine = per-pixel shader noise.

Caustics are physically derived: `WaterCaustics.shader` computes the focusing (`-Laplacian`) of a domain-warped water height field — the same lensing that drives screen distortion. NOT random noise multiply.

**Flow field (currents):** `FlowFieldManager` builds a CPU curl-noise (divergence-free FBM) field, consumed by cells via `FlowFieldPush.cs` (on player prefab + added to AI in `CellVariety.Apply`) which pushes ALL soft-body rigidbodies mass-scaled. `PlanetaryEnvironment.SampleAndApply` is the continuous authority (every `updateRate`=0.2s) and drives `turbulence`/`baseStrength`/`noiseScale`/`noiseSpeed`; knobs there: `currentIntensity` (master, default 5), `swirlScale` (vortex size, smaller=swirlier), `swirlSpeed`. `EnvironmentController` also writes flow but only on biome change.

Debugging 2026-08-10 "currents have no effect / arrows uniform" — chased THREE stacked bugs: (1) `PlanetaryEnvironment` throttled turbulence/strength to ~0.15 (fixed w/ currentIntensity master); (2) `UpdateWeather` hard-`Clamp01`'d effectiveTurbulence whenever WeatherSystem present (→ `Min(...,8)`); (3) THE BIG ONE — `SampleFlowAtPosition` returned a FLAT `baseDirection*baseStrength` for any position outside `fieldBounds`, and the bounds didn't track the player once it roamed past ±50 from origin, so the whole field collapsed to uniform drift away from spawn. Also `Mathf.PerlinNoise` goes flat at large coords (big time offset / far world pos), killing swirl. Fixes: replaced Perlin FBM with a wrap-safe integer-lattice value noise (`Hash`/`VNoise`); `SampleFlowAtPosition` now falls back to analytic `EvaluateFlow` (curl+drift) when out of grid; `UpdateBounds` re-fetches Camera.main so the field follows the view. After fixes, center speed went 0.12 → 5–8 with clear vortices. Debug overlay: `FlowFieldDebugArrows` (on FlowFieldManager GO) — press **F** in play to toggle. It draws via GL in OnGUI (immune to the full-screen water distortion) with a speed readout; arrows coloured cyan(slow)→magenta(fast). Arrows are pinned to a fixed WORLD lattice (`worldSpacing`, multiples projected each frame) so they scroll/scale with the camera — NOT screen-locked (an earlier version laid them across the viewport, which looked screen-tied).

2026-08-11 (part 2) — currents reworked for "calm water with streams + still/lively regions": FlowFieldManager is now the SINGLE source of truth. BOTH overriders were removed — `PlanetaryEnvironment.SampleAndApply` no longer pushes flow params, and `EnvironmentController.ApplyBiome`/`TransitionToBiome` no longer call SetBaseFlow/SetTurbulence (they were clobbering hand-tuned FlowFieldManager values — EnvironmentController was the reason noiseScale reset to 5 and baseStrength to ~0.97 "wind"). Field math changed from raw curl-of-FBM to a **stream function** ψ (`StreamFunction()`): domain-warped (`meander`) large-scale low-octave value-noise potential + optional **jet-stream** bands (`jetStrength/jetScale/jetBands`), with flow = central-difference curl (`curlGain` calibrates magnitude). Coherent connected streamlines + jets, not pointwise-random. A **liveliness map** (`EnergyMap`, replaced TurbulenceMul) gates the whole flow: world-fixed value noise, biased low via e²·`livelyBoost`, `stillThreshold`/`livelyThreshold` → mostly calm, DEAD-STILL below stillThreshold, sparse very-lively patches. Debug arrows (F) draw a dim dot for still water. Good calm-water values: turbulence 0.54, noiseScale 50, noiseSpeed 0.05, baseStrength ~0.1, baseDirection 0, energyRegionScale ~28, stillThreshold 0.5, livelyThreshold 0.72, livelyBoost 4. Deferred (user parked it): cell-pop splatter pieces should be smaller, less circular, fly less fast/far.

2026-08-11 follow-up tuning ("too strong/unpredictable", "add turbulent regions"): curl amplitude 7→4.5; `currentIntensity` 5→2.5, `swirlScale` 5→9 (bigger gentler eddies), `swirlSpeed` 0.7→0.25 (slow, predictable churn), turbulence floor 0.6→0.25; `FlowFieldPush.strength` 6→2.5 (player instance updated too). Added a **spatial turbulence map** in FlowFieldManager (`turbulenceRegionScale`, `turbulenceVariation`): a time-independent, world-fixed value-noise multiplier on the curl, so the pool has broad calm vs rough patches (center speed ranges ~0.5 in calm to ~5 in rough) — learnable, not uniform. Applied in both `UpdateCPU` and `EvaluateFlow`.

**Gotchas:** Unity does NOT propagate changed C# default field values to already-serialized scene components — must Reset the component (right-click → Reset) or edit in Inspector. `FlowFieldManager.noiseScale` had been serialized to 0 (divide-by-zero → NaN flow); keep it ~10. Full-screen distortion warps the cell too; low distortion `noiseScale` (~2) shears the whole cell into a triangle — keep ~8 for fine edge ripple. The ~8 console "errors" are Unity AI generator network failures (generators-beta.ai.unity.com), unrelated to game code.
